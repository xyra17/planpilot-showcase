# 学习伙伴与任务协作页面重写记录

## 目标

把原本偏数据仪表盘的学习伙伴页、偏技术调试台的 Agent 工作台，改为两个边界清晰的用户产品页面。

## 学习对话

- 主区域按照“今日观察 → 复习提醒 → 可执行建议 → 用户确认与反馈”组织。
- Proposal 的接受、拒绝、调整、应用和效果反馈状态机保持不变。
- 学习状态、行为依据、长期记忆和反馈指标收进右侧决策上下文栏。
- 每条观察显示 Pattern、证据数量和置信度，继续支持“为什么这样建议”的解释体验。
- 所有业务数据变更仍必须经过用户确认。

## 任务协作

- 页面名称由“Agent 工作台”调整为“任务协作”。
- 交互语言改为用户流程：描述任务、生成执行计划、确认变更、执行结果。
- 历史任务改为“最近协作”，降低技术后台感。
- 安全提示明确显示“所有变更需确认”。
- Agent Runtime、执行步骤、审批、撤销、审计和失败恢复能力保持兼容。

## 主题与响应式

- 使用界面风格语义变量，不固定为单一白色主题。
- 暗色、护眼和手账模式分别继承对应背景、边框和文字颜色。
- 桌面端采用对话区与上下文栏双列；窄屏自动改为单列。
- 手账模式使用较轻的虚线和不规则圆角，避免黑色重边框压迫内容。
