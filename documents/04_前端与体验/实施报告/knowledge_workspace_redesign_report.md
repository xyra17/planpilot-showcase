# 知识库资料工作台重构报告

## 目标

本次重构不改变知识库业务能力，集中解决页面标题、资料导航、导入操作、文件状态和 AI 摘录彼此割裂的问题。最终采用连续、紧凑的资料工作区，不使用多层悬浮卡片，同时保持默认、暗黑、护眼和手账纸稿四套界面风格隔离。

## 页面结构

- 建立两级页面层级：`/work/knowledge` 是资料空间一级页，`/work/knowledge/[id]` 是单个知识库二级页。
- 一级页负责知识库集合、全部资料、AI 对话摘录和全局导入；知识库不再作为一级页内部的临时筛选项。
- 一级页使用“知识库 / 全部资料 / AI 摘录”内容标签，一次只呈现一类信息，避免三组高密度内容同时堆叠。
- 默认知识库集合增加卡片尺寸、栏目留白和自适应网格；宽屏保持充分利用，窄屏自动降为单列。
- 二级页负责单库说明、处理概览、资料搜索、上传、网址导入、失败重试、资料删除和知识库管理。
- 顶部使用单行知识库工具栏，合并页面说明、当前筛选、导入网址和上传资料操作。
- 资料处理概览压缩为行内状态，分别显示全部资料、可用于 AI、处理中和需处理数量。
- 左侧导航改为紧凑的“资料空间”，收起按钮紧邻标题；全部资料、待分类资料和目标均显示对应数量。
- 资料导航和主内容使用同一层主题底面，仅用细分隔线表达层级，避免形成第三套独立模块。
- 资料区域合并筛选标题、说明、搜索和视图切换，减少悬空控件和重复标题。
- 列表行把文件名、大小、状态、归属和更新时间重新分层；失败状态与重试动作保持在同一个操作组内。
- 全部资料和学习对话摘录进入同一个连续内容流，只用栏目分隔线区分，并提供前往学习伙伴的明确入口。

## 主题与响应式

- 所有新增表面、边框、文字和状态均使用语义主题变量，不写死白色背景。
- 暗黑风格使用深色分层表面和独立状态色。
- 手账纸稿风格保留纸张背景、虚线轮廓、不规则圆角与手绘感图标容器。
- 窄屏下统计改为两列，工具栏纵向排列，文件表格降级为可读的卡片行。

## 兼容性

保留文件上传、URL 导入、知识库与目标筛选、列表/卡片切换、文件重试、文件删除、AI 摘录展开与编辑等既有行为。没有修改后端接口或数据模型。

知识库二级页直接复用现有 `GET/PATCH/DELETE /api/v1/knowledge/kbs/{id}` 以及文件上传、网址导入、重试和删除接口，因此没有增加平行数据源。

## 验证

- `npm run lint`
- `npm run build`
- Playwright 主题隔离与知识库关键入口断言
- 浏览器检查默认、暗黑、手账纸稿三种实际渲染
