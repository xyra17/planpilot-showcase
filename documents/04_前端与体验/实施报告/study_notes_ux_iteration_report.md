# 学习记录 UX 第二轮验收报告

日期：2026-07-26

## 一、迭代目标

本轮以日常使用体验为优先，完成学习记录的目标/任务双层关联、标题与时间
正确性修复，以及接近 Notion/思源笔记的信息层级和编辑交互调整。

## 二、完成内容

### 2.1 目标与任务关联

- `goal_id` 继续作为学习记录的长期主要归属；
- `task_id` 为可选关联，任务必须属于所选目标；
- 更换目标时，前端清空不匹配的任务，后端再次校验；
- 新增 `task_title_snapshot`，任务删除后笔记仍保留原任务名称；
- `task_id` 外键改为 `ON DELETE SET NULL`，删除任务不会删除学习记录；
- 任务下拉按目标加载，并显示任务名称和计划日期。

### 2.2 标题与时间

- 无标题笔记不再把 HTML 正文写进 `title`；
- 历史数据即使包含 `<p>...</p>`，列表也只展示纯文本；
- 无显式标题时，使用正文纯文本前 52 字作为视觉标题，不写回数据库；
- 新增 `updated_at`，API 分别返回 `createdAt`、`updatedAt`；
- 时间统一以带 `Z` 的 UTC ISO 字符串返回，前端按本地时区展示；
- 列表显示“刚刚 / N 分钟前 / N 小时前 / N 天前”，悬停显示完整时间；
- 迁移时旧数据的 `updated_at` 由原 `created_at` 回填，避免全部显示为刚刚编辑。

### 2.3 前端编辑体验

- 标题改为大字号无边框输入，空标题提示为“无标题”；
- 目标与任务放入统一的属性栏；
- 卡片按“目标/任务标签 → 标题 → 摘要 → 附件/编辑时间”展示；
- 增加“未保存 / 保存中 / 已保存 / 保存失败”状态；
- 新建草稿取消时删除草稿及其专属附件；
- 工具栏改为紧凑图标分组，增加撤销、重做和文本样式下拉；
- `/` 菜单增加标题、列表、待办、引用、分割线等普通区块，同时保留 AI 指令；
- 保留上一轮完成的图片完整显示、滚动、拖拽缩放及快捷尺寸功能。

## 五、人工体验重点

请重点检查：

1. 新建笔记时选择目标后，任务选项是否符合直觉；
2. 无标题笔记在列表中的标题和摘要是否重复过多；
3. 工具栏图标密度、横向滚动和 `/` 菜单是否顺手；
4. 长正文、超大图片及多个附件时的滚动体验；
5. 相对时间文案是否符合预期。

浏览器自动验收未代填用户凭据，因此登录后的最终视觉判断留给用户实际体验。
