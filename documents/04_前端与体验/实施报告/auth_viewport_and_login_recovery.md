# 登录页单屏适配与登录恢复记录

## 页面适配

- 登录布局使用动态视口高度，避免浏览器工具栏导致页面被裁切。
- 桌面端低于 700px 高度时自动压缩品牌区留白、介绍文字和表单卡片内边距。
- 移动端登录页保持单列，并固定在一屏内完整显示表单与注册入口。

## 登录故障

- 根因：本机 SEKAP 开发服务与 PlanPilot Docker API 同时使用 8000 端口。
- 影响：浏览器的 `/api/v1/auth/login` 请求命中 SEKAP，返回 404。
- 处理：停止冲突的 SEKAP 本地开发进程，保留 PlanPilot Docker API。
- 验证：PlanPilot 登录接口恢复 200，真实前端登录流程可正常进入学习空间。
