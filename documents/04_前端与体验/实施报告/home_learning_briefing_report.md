# 首页学习简报 UI 优化报告

## 目标

优化首页日期、用户问候、高效学习时段、置信度和行动建议的展示层级，并消除个人简报与“今日复习提示”两个 AI 建议区域重复竞争主视觉的问题。

## 调整

- 欢迎区恢复旧版紧凑结构：左侧问候与洞察、右侧三个独立小统计卡。
- 删除日期和“今日任务”辅助行，避免重复占用首屏空间。
- 问候恢复为旧版主标题尺寸，并将挥手表情与用户名留出稳定间距。
- 高效学习时段与一句行动建议直接放在问候语下方，以轻量文字展示，不使用独立卡片。
- 顶部洞察不再显示“今日节奏建议”、置信度或“查看依据”等次要信息，避免首页首屏信息过载。
- 紫色“今日复习提示”只保留具体复习行动，不再重复高效时段洞察。
- 删除紫色区域中与行动重复的昨日总结正文，让主操作保持单一。
- 本周时长、进行目标和今日完成恢复为旧版约 84px 的居中小卡，不随左侧内容纵向拉伸。
- 窄屏时摘要自动换为纵向布局，长用户名不会挤压洞察内容。

## 主题

新增样式全部使用主题语义变量。默认、暗黑、护眼和手账纸稿风格分别继承自己的背景、边框、强调色和状态色；手账模式额外保留虚线和不规则圆角。

## 验证

- 前端 lint 和 production build。
- 浏览器检查默认与暗黑实际渲染。
- E2E 检查日期、问候下方的高效时段、行动建议、三项摘要，以及紫色区域不存在重复洞察。
