# 后台导航与页面隔离实施报告

完成日期：2026-07-31。

## 目标

将原先集中在 `/admin` 的长页面拆分为由左侧导航驱动的独立后台页面。管理员进入任一页面时，先看到明确的图标、标题和一句操作指引，再看到该模块内容。

## 路由结构

| 左侧导航 | 路由 | 页面职责 |
|---|---|---|
| 运营总览 | `/admin` | 核心指标、生产策略、健康与漂移、反馈链路 |
| Canary 发布 | `/admin/canary` | 生产门禁、分阶段放量、暂停与回滚 |
| 实验与评估 | `/admin/experiments` | 版本记录、离线评估、生产门禁记录、在线实验 |
| 模型网关 | `/admin/gateway` | 分布式熔断状态与模型路由健康 |
| Agent Trace | `/admin/traces` | 最近调用和单次运行时间线 |

## 交互约束

- 左侧导航使用真实页面路由，不再使用同页锚点。
- 当前路由具有唯一选中状态和 `aria-current="page"`。
- 页面标题由后台外壳统一生成，避免各页面重复实现和视觉漂移。
- 页面级操作只出现在相关模块，例如生产门禁只位于 Canary 页面。
- Admin 继续使用固定运营后台主题，不继承用户设置中的界面风格。
- 移动端继续复用后台抽屉导航。

## 验证

- 前端 lint 与生产构建。
- Canary E2E 覆盖五个后台导航入口、独立路由和标题。
- 浏览器检查总览和 Canary 页面，确认标题区、导航选中态和内容边界清晰。
