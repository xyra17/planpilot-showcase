# PlanPilot 前端页面要素说明

> 文档状态：当前实现基线
> 更新日期：2026-07-31
> 适用目录：`frontend/app/`、`frontend/components/`
> 说明：本文以当前真实代码为准，记录页面职责、主要界面要素、用户操作、页面状态与访问边界。它是后续前端改版和验收的页面地图，不是视觉稿。

## 1. 页面体系

PlanPilot 前端目前分成四个相互隔离的区域：

| 区域 | 正式入口 | 访问者 | 外壳 |
| --- | --- | --- | --- |
| 公开认证 | `/login` 等 | 未登录用户 | Auth Layout |
| 学习空间 | `/work` | 普通用户、管理员 | Product Shell / 学习空间模式 |
| 学习伙伴 | `/coach` | 普通用户、管理员 | Product Shell / 学习伙伴模式 |
| 管理后台 | `/admin` | 仅管理员 | Admin Shell |

根路由 `/` 不承载页面内容，进入后跳转至 `/work`。`/dashboard/*` 是历史兼容路由，不再作为导航中的正式入口。

### 1.1 全局导航要素

普通产品区域使用统一左侧导航：

- 品牌区：PlanPilot 标识、产品说明、通知入口和导航收起按钮。
- 模式切换：`学习空间` 与 `学习伙伴`，用于区分日常学习管理和智能协作。
- 学习空间导航：总览、目标、资料、笔记。
- 学习伙伴导航：学习对话、任务协作。
- 管理后台入口：仅 `is_admin` 用户可见。
- 用户区：头像、用户名、邮箱和设置入口。

管理后台使用独立导航，不与普通用户功能混排。后台的页面标题、图标和简短指引随当前页面切换。

### 1.2 全局交互规范

每个业务页面至少需要处理以下状态：

- 首次加载：骨架、加载图标或明确的加载文字。
- 空状态：解释当前为什么没有内容，并提供下一步操作。
- 请求失败：说明失败对象，并提供重试或返回入口。
- 提交中：禁用重复操作，按钮显示进行中状态。
- 成功反馈：使用 Toast、状态提示或更新后的界面结果。
- 破坏性操作：删除、注销、回滚等必须二次确认。
- 权限状态：未登录跳转登录页；非管理员不能进入后台。
- 响应式状态：窄屏下侧栏、双栏或工作台面板可以收起。

界面风格由设置页控制。默认、暗色、护眼、手账风格拥有各自隔离的页面与组件样式；状态徽标、空状态、弹窗、输入框等小组件也必须跟随当前风格变化。

## 3. 公开认证页面

认证页面采用完整视口布局。左侧负责品牌与产品价值表达，右侧放置单一认证任务，页面不应出现需要滚动后才能完成的核心表单。

### 3.1 登录 `/login`

**主要要素**

- 欢迎标题与登录说明。
- 邮箱输入框。
- 密码输入框。
- “忘记密码”入口。
- 登录按钮。
- “创建账号”入口。

**主要操作与状态**

- 提交邮箱和密码，成功后进入学习空间。
- 表单校验、登录中状态和接口错误提示。
- 已登录用户不应重复停留在登录页。

### 3.2 注册 `/register`

**主要要素**

- 用户名、邮箱和密码输入框。
- 注册按钮。
- 返回登录入口。

**主要操作与状态**

- 校验必填项和密码规则。
- 创建账号后建立登录会话或引导登录。
- 展示邮箱重复、用户名冲突等错误。

### 3.3 忘记密码 `/forgot-password`

**主要要素**

- 邮箱输入框。
- 发送重置链接按钮。
- 返回登录入口。

**主要操作与状态**

- 提交前显示说明，提交后显示已发送状态。
- 无论账号是否存在，都应避免泄露用户注册信息。

### 3.4 重置密码 `/reset-password`

**主要要素**

- 新密码与确认密码输入框。
- 重置按钮。
- 返回登录入口。

**主要操作与状态**

- 从地址参数读取并验证重置令牌。
- 处理令牌缺失、失效、密码不一致和提交失败。
- 成功后引导用户重新登录。

## 4. 学习空间页面

### 4.1 学习总览 `/work`

该页面是用户每天进入 PlanPilot 后的行动首页，重点是“今天做什么”和“最近学得怎么样”，而不是展示后台指标。

**主要要素**

- 欢迎区：时段问候、用户名和简短的个性化学习洞察。
- 今日复习提示：保留一条最重要的复习建议和直接行动入口。
- 三项紧凑指标：本周学习时长、进行中目标、今日完成任务。
- 学习时长趋势：支持周、月、年粒度切换。
- 学习热力图：展示一段时间内的学习活跃度。
- 今日任务：任务列表、完成状态、优先级和快速操作。
- 今日打卡：填写或查看当天的学习反馈。
- 目标进度：当前目标的阶段与完成进度。
- 日程面板：以列表或时间线查看当天学习安排。

**主要操作**

- 新建、编辑、删除和完成今日任务。
- 搜索任务，调整优先级或打开关联目标。
- 开始今日复习。
- 打开日程编辑器，调整时间块或请求智能排程。
- 提交今日打卡。

**特殊状态**

- 新用户没有目标时显示引导式欢迎内容。
- 没有学习洞察时使用通用建议，不显示虚构置信度。
- 无任务、无打卡、无趋势数据各自拥有独立空状态。

### 4.2 目标列表 `/work/goals`

**主要要素**

- 页面标题与“新建目标”主操作。
- 目标卡片：名称、目标类型、每日投入、状态或完成率。
- 进度条、截止日期和剩余时间。
- 编辑与删除操作。

**主要操作与状态**

- 点击目标卡片进入目标详情。
- 编辑目标或确认删除目标。
- 删除时可根据业务关系选择是否同时处理关联知识库。
- 支持加载、空列表、删除失败与无权访问状态。

### 4.3 新建目标 `/work/goals/new`

**基础表单要素**

- 目标类型：备考、认证、技能、阅读、语言学习、习惯养成。
- 目标名称、截止日期和每日投入时长。
- 学习日安排：工作日、周末或每天。
- 当前水平：初学、进阶、高阶。
- 知识库关系：关联已有知识库，或随目标创建待完善知识库。
- 可选资料：文件、网址或补充说明。

**AI 计划流程**

- 目标创建成功后询问是否生成 AI 学习计划。
- 选择知识来源、学习节奏和补充意图。
- 预览阶段划分、日期范围、任务类型和每日任务。
- 重新生成、确认启用或跳过计划。
- 可选择把当天计划任务同步到今日待办。

**主要状态**

- 表单校验、创建中、创建失败。
- 计划生成中、生成失败、重新生成和确认启用。

### 4.4 目标详情 `/work/goals/[id]`

目标详情是一个可折叠、可调整宽度的双区工作台。

**顶部要素**

- 返回目标列表的面包屑。
- 目标名称、截止日期、计划天数或剩余天数、每日投入和目标状态。

**左侧目标执行区**

- 数据指标：目标进度概览和学习债务提示，可折叠。
- “任务”页签：今日任务、日期选择、任务完成、验证和掌握度记录。
- “相关笔记”页签：查看和维护与当前目标关联的笔记。
- 左侧面板可收起，桌面端可拖动调整宽度。

**右侧智能协作区**

- “AI 助教”页签：围绕当前目标进行上下文对话。
- “学习计划”页签：查看阶段、日期、任务与掌握状态。
- 重新规划时间入口；执行前显示确认，完成后展示预计完成日期变化。
- 右侧面板可独立收起。

**特殊状态**

- 目标加载中、目标不存在或无权访问。
- 任务验证弹窗、重新规划确认弹窗与规划结果提示。
- 窄屏默认收起智能协作区，避免主任务区过于局促。

### 4.5 编辑目标 `/work/goals/[id]/edit`

**主要要素**

- 与新建目标一致的核心字段：类型、名称、截止日期、每日投入、学习日和当前水平。
- 目标状态：进行中、暂停、完成、放弃。
- 保存、取消和返回入口。

**主要状态**

- 加载原始目标、目标不存在、字段校验、保存中与保存失败。

### 4.6 资料空间 `/work/knowledge`

资料空间是一级聚合页，集中展示所有知识库、学习资料和 AI 对话摘录。

**顶部与概览要素**

- 页面标题“资料空间”和简短说明。
- 导入网址、上传资料、新建知识库。
- 资料统计：全部、可用于 AI、处理中、需要处理。

**知识库区域**

- “我的知识库”列表或卡片。
- 每个知识库显示名称、说明、资料数和可用于 AI 的资料数。
- 点击进入知识库详情。

**全部资料区域**

- 搜索框和列表/卡片视图切换。
- 资料名称、类型、大小、更新时间。
- 处理状态：处理中、可用、处理失败等语义状态徽标。
- 所属知识库与关联目标标签。
- 失败资料的重试入口和资料删除操作。

**AI 对话摘录区域**

- 已保存摘录的标题、回答、引用和关联信息。
- 展开查看、编辑回答、保存和删除。
- 无摘录时显示说明和前往学习伙伴的入口。

**弹窗与状态**

- 新建知识库弹窗。
- 上传资料弹窗：选择知识库，并可关联目标或任务。
- URL 导入弹窗。
- 上传、解析、重试、删除的进行中与失败状态。

### 4.7 知识库详情 `/work/knowledge/[id]`

知识库详情是资料空间下的二级页面，只处理单个知识库范围内的内容。

**主要要素**

- 返回资料空间。
- 知识库名称、说明、资料总数和可用于 AI 的数量。
- 编辑信息、导入网址、上传资料和删除知识库。
- 资料搜索和列表/卡片视图。
- 资料处理状态、关联信息和删除操作。

**主要状态**

- 加载、知识库不存在或无权访问、空知识库。
- 上传与网址导入弹窗自动绑定当前知识库。
- 删除知识库前必须显示影响范围并二次确认。

### 4.8 笔记 `/work/notes`

**页面级要素**

- “学习记录”和“备忘录”两个页签。
- 可通过 `goalId` 只查看某个目标的笔记，并提供“查看全部”。
- 可通过地址参数直接进入新建状态。

**学习记录页签**

- 周日期带与月历，用于选择记录日期。
- 当天学习记录列表。
- 富文本编辑器，支持标题和正文。
- 关联目标与关联任务。
- 添加附件。
- 自动保存状态：已保存、未保存、保存中、保存失败。
- 切换日期或离开未保存内容时显示放弃修改确认。

**备忘录页签**

- 搜索、日期筛选和新建入口。
- 卡片或列表式笔记浏览。
- 查看、编辑、删除以及目标关联。
- 空状态和加载状态。

> 当前实现中，部分内部组件仍使用“学习日志”旧称；产品导航以“学习记录 / 备忘录”为准，后续文案收口时应统一。

## 5. 学习伙伴页面

### 5.1 学习对话 `/coach`

学习对话用于呈现“学习伙伴看到了什么、为什么这样建议、用户是否采纳”，不允许 Agent 绕过提案机制直接修改业务数据。

**对话主区**

- 页面标题、目标范围选择和刷新学习数据。
- 今日观察：行为模式、证据数量和定性证据强度；不把证据强度展示成用户动机概率。
- 知识缺口或复习提醒。
- AI 建议卡片：建议内容、依据、影响范围和状态。
- 建议生命周期：创建、接受、拒绝、应用、反馈。
- 生成新建议和生成自适应计划入口。

**决策依据区**

- 当前学习状态：完成率、持续性、偏好时段和近期事件。
- 活跃模式及证据来源；延期模式可展开具体延期记录，标记外部中断并重新计入。
- 相关长期记忆。
- 历史接受率、拒绝率和建议效果。

**主要操作与状态**

- 接受、拒绝或调整建议；接受后再单独应用。
- 应用后提交效果反馈。
- 处理无画像、证据不足、无建议、加载失败和数据更新中。

### 5.2 任务协作 `/coach/workbench`

任务协作用于复杂任务协作。学习伙伴把用户意图转成可查看、可修改、可批准的执行计划，并保留完整执行边界。

**任务输入区**

- 任务描述输入框。
- 目标范围选择。
- 快捷意图：分析、重新安排、创建、调整、删除。
- 开始协作按钮。

**协作过程区**

- 最近协作历史：载入、折叠和删除。
- 当前运行状态与上下文摘要。
- 分步骤执行计划及计划版本。
- Agent 生成的变更集和影响说明。
- 用户批准、修改或拒绝变更。

**运行控制与结果区**

- 暂停、取消、重试、重新规划和回滚。
- 证据、结论、执行时间线和审计记录。
- 模型、工具或执行失败后的可恢复状态。
- 明确提示“所有业务变更都需要用户确认”。

## 6. 设置页面

### 6.1 设置 `/settings`

**界面风格**

- 默认、暗色、护眼和手账四种风格模式。
- 每种风格显示名称、说明和视觉预览。
- 默认、暗色、护眼使用各自的配色选项。
- 手账风格使用独立手账配色，不与其他模式共用样式变量。
- 选择结果即时作用于页面、弹窗和语义状态组件。

**账号管理**

- 修改用户名。
- 修改邮箱。
- 使用当前密码修改新密码。
- 查看加入时间。
- 设置学习时区：中国、东京、纽约、伦敦或 UTC。
- 退出登录。
- 注销账号：显示数据永久删除说明和倒计时确认。

**主要状态**

- 行内编辑、字段错误、保存中、保存成功和保存失败。
- 注销账号进行中和注销失败。

## 7. 管理后台页面

管理后台仅管理员可见。普通用户导航中不显示入口，即使直接输入地址也必须由权限边界拦截。五个后台页面共用运营数据组件，但各自聚焦不同视图。

### 7.1 运营总览 `/admin`

**主要要素**

- 最新生产质量门禁结果。
- 当前线上 Prompt、模型和策略版本。
- Agent 健康度、质量、安全与漂移摘要。
- 最近离线评估和生产门禁记录。
- 线上实验、模型网关和最近 Agent 运行概览。
- 反馈学习链路和异常提醒。

**主要操作**

- 刷新运营数据。
- 触发允许范围内的评估、监控或校准任务。
- 跳转到 Canary、网关、实验或追踪详情。

### 7.2 Canary 发布 `/admin/canary`

**主要要素**

- 当前 Canary 实验、变体和流量阶段。
- 支持的阶段：内部、1%、5%、20%、50%、100%。
- 暴露量、接受率、完成率提升、错误率、延迟和成本。
- Safety 指标、漂移状态和回滚条件。

**主要操作与边界**

- 在离线质量门禁通过后创建或启动 Canary。
- 推进阶段、暂停发布或回滚。
- 阶段变更和回滚均需确认并留下记录。

### 7.3 实验与离线评估 `/admin/experiments`

**主要要素**

- Prompt、模型、策略版本和部署状态。
- 实验列表、变体与用户分配摘要。
- Benchmark 与最近离线评估结果。
- 推荐质量、规划质量和安全指标。
- Offline Gate 通过/阻断原因及历史记录。

**主要操作**

- 运行评估或生产质量门禁。
- 查看实验详情和版本表现。
- 只允许通过质量门禁的版本进入发布流程。

### 7.4 模型网关 `/admin/gateway`

**主要要素**

- 主模型与 fallback 模型状态。
- 调用成功率、失败数、超时、重试和延迟。
- 分布式熔断器状态：关闭、打开、半开。
- 按模型或 Worker 查看共享熔断状态和恢复时间。
- 网关异常与降级提示。

**主要操作**

- 刷新实时状态。
- 查看故障聚合和模型降级记录。
- 运维操作必须遵守现有恢复和回滚策略。

### 7.5 Agent 调用追踪 `/admin/traces`

**主要要素**

- 最近 Agent 运行列表。
- 运行类型、用户范围、成功状态、延迟、Token 和成本。
- Trace 详情及 Span 时间线。
- 上下文检索、模型调用、工具调用、提案和用户动作节点。
- 单节点错误、耗时和输入输出摘要。

**主要操作**

- 选择一次运行查看完整调用链。
- 按状态或运行类型定位异常。
- 从失败节点回溯模型网关、工具或业务服务问题。

## 8. 历史兼容路由

以下路由用于兼容旧链接，当前导航和新文档不应再以它们作为产品入口：

- `/dashboard` → 学习总览。
- `/dashboard/goals`、`/dashboard/goals/new`、`/dashboard/goals/[id]`、`/dashboard/goals/[id]/edit` → 目标页面。
- `/dashboard/knowledge`、`/dashboard/knowledge/[id]` → 资料页面。
- `/dashboard/notes` → 笔记页面。
- `/dashboard/coach` → 学习对话。
- `/dashboard/agent` → 任务协作的历史入口。
- `/dashboard/settings` → 设置页面。
- `/dashboard/agent-operations` → 管理运营页的历史实现入口，仅供兼容或内部迁移。

新增导航、站内链接和产品文档必须使用 `/work`、`/coach`、`/settings`、`/admin` 路由。兼容路由在确认没有外部引用后再单独制定移除计划。

## 9. 后续改版验收清单

调整任一页面时，应同时核对：

1. 页面目的没有被装饰性信息稀释，首屏主操作明确。
2. 普通功能、AI 功能和管理功能仍保持区域隔离。
3. 页面标题、图标和一句话指引与当前路由一致。
4. 默认、暗色、护眼、手账四种界面风格下均可读、可操作。
5. 处理状态、标签、按钮、空状态和弹窗跟随界面风格。
6. 加载、空数据、失败、无权限和提交中状态完整。
7. Agent 产生的业务变更仍经过 Proposal、用户确认和 Apply。
8. 新页面同时提供正确导航入口、返回路径和响应式行为。
9. 正式站内链接不再新增 `/dashboard/*` 引用。
