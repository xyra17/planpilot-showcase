# 前端体验收口实施报告

日期：2026-07-26  
回退标签：`backup/frontend-ux-consolidation-start-20260726`

## 一、目标

本轮停止按页面追加零散样式，集中收口工作区导航、空状态、反馈、目标与笔记联动、
响应式和可访问性。后端接口及数据库结构未改动。

## 二、公共组件

- 新增 `WorkspaceHeader`：统一笔记、我的目标和知识库的顶部一级导航；
- 新增 `EmptyState`：统一空数据的标题、说明、图标和下一步操作；
- 新增 `ToastProvider`：统一成功、错误和普通提示，最多显示三条并自动消失；
- 新增 `ConfirmDialogProvider`：统一危险操作确认，支持 Esc、遮罩关闭、初始焦点和危险操作语义；
- Dashboard 全局接入 Toast，颜色继续由当前主题变量控制。

## 三、信息架构

- 从目标详情进入笔记中心时，页面真正按 `goalId` 筛选关联内容；
- 页面顶部明确显示“仅显示当前目标关联的内容”，并可一键返回全部；
- 学习笔记和学习日志仍使用既有数据类型，不迁移数据；
- 目标详情页维持“相关笔记”只读聚合，编辑继续在笔记中心完成。

## 四、反馈与编辑器

- 知识库上传、网址导入、重试、删除和创建分组改为 Toast 反馈；
- 学习笔记及学习日志删除增加确认和结果反馈；
- 目标删除、关联知识库处理、学习笔记删除和学习日志删除不再调用浏览器原生确认框；
- 学习日志保存增加明确成功/失败反馈；
- 编辑器图片上传不再静默失败，补充成功和错误提示；
- 图片尺寸激活状态不再固定使用蓝色，改为当前主题色。
- 修复手账主题把带有 `hover:bg-blue-*` 的轻量按钮误判为深色主按钮的问题；
- 目标卡片编辑、删除操作统一为同尺寸的轻量描边图标按钮；
- 学习笔记日期导航“周期”改名为“周历”，今天增加主题色纸片底、细边框和文字标记。
- 目标详情页将“今日任务 / 任务日历”合并为单一任务工作区，顶层仅保留“任务 / 相关笔记”，今日清单与日历改为组件内部切换；
- 日历视图补充“回到今天”，今日视图保留检索、完成状态和验收入口，避免两个入口表达同一任务数据；
- AI 助教六个快捷操作移除彩色 Emoji，统一为可点击的 Lucide 线稿图标；手账主题下使用纸片轮廓、虚线墨迹底座和主题色悬停反馈。
- 修复手账新建学习笔记标题被通用表单规则包成厚边框输入框的问题，恢复无边框文档标题；
- 为 Tiptap 工具栏、正文滚动区建立独立样式边界，清除编辑区异常横向绘制，并将正文分隔线统一为轻量虚线；
- 全面统一手账页面、弹窗、卡片、编辑器的纵横滚动条与 range 滑栏，颜色随原木、青灰、旧报纸和夜色配色变量变化；工具栏保留横向滚动能力但隐藏干扰性的轨道。
- 修正手账滚动条选择器未稳定命中 `<html>` 根滚动容器的问题，首页全局、目标进度、今日时间规划及所有内部滚动区统一覆盖；
- 四套手账配色分别增加滚动轨道、滑块和悬停色令牌，保持整体统一，同时用明确的三级明暗层次区分可滚动轨道与可拖动滑块。
- 首页七个核心模块统一标题字号、字重、行高及 28px 图标容器；学习热力图仅标题保持左对齐，其月份导航、图块和图例作为整体居中。
- “我的目标”移除重复的“目标总览 / 管理和追踪你的学习目标”说明区，页面直接进入目标内容。
- 首页目标进度列表移除负边距并收窄内容区，禁止横向溢出；目标悬停状态改为主题浅色纸片反馈，不再继承不协调的灰色。
- 目标进度和今日时间规划使用低存在感的专用纵向滚动条：透明轨道、配色对应的柔和滑块、主题色悬停，并彻底隐藏横向滚动条。
- 重构手账弹窗基座：移除外壳强制滚动和强制宽高，避免 SVG 负边距触发横纵滚动条；
- 弹窗不规则边框收回纸片内部，恢复各组件自身的尺寸与内容滚动策略；
- 弹窗纸面改为轻微纤维纹理，标题与操作区使用虚线分隔，并加入低透明度胶带装饰；
- 手账弹窗关闭按钮、桌面纸片阴影和移动端底部弹层样式统一。

## 五、响应式与可访问性

- 768px 以下全局侧栏自动压缩为图标栏；
- 知识库资料栏、学习笔记日期栏在窄屏默认收起；
- 目标详情页在窄屏默认收起 AI 面板，任务区域优先占据可用宽度；
- 工作区顶部导航允许横向滚动，操作按钮保持在右侧；
- 知识库搜索与操作栏允许换行，资料卡片改为 1 / 2 / 3 列响应式网格；
- 主要弹窗补充 `dialog`、`aria-modal` 和可访问名称；
- 已有键盘焦点、减少动画、强制高对比度和主题滚动条规则继续生效。
