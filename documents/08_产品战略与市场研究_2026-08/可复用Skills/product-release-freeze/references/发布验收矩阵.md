# 发布验收矩阵

根据当前产品和发行目标选择相关部分，不要求每次加载或执行全部项目。

## 通用产品闭环

| 领域 | 最低证据 | 常见阻塞 |
| --- | --- | --- |
| 首次进入 | 新用户或干净状态真实走通 | 无入口、无说明、必须理解内部配置 |
| 核心任务 | 从入口到成功结果完整走通 | 中途断链、假控件、成功无反馈 |
| 失败恢复 | 模拟主要失败并能够重试或返回 | 白屏、数据丢失、只能重装 |
| 再次进入 | 重启或重新登录后状态符合承诺 | 会话丢失、数据卷失联、重复初始化 |
| 权限与隐私 | 未授权访问被拒绝，数据归属清楚 | 越权、敏感信息进入日志或前端 |

## Web 产品

| 领域 | 建议检查 |
| --- | --- |
| 构建 | 当前提交的生产构建、类型和静态检查 |
| 路由 | 正式入口、刷新、深链、404 和返回路径 |
| 浏览器 | 目标桌面宽度、375px、主要交互状态和溢出 |
| 后端 | 健康检查、数据库连接、迁移、队列与存储 |
| 配置 | 环境变量、API 地址、跨域、HTTPS 与秘密信息 |
| 可恢复性 | 请求失败、超时、重试和重复提交 |

## 桌面应用

| 领域 | 建议检查 |
| --- | --- |
| 产物 | 直接从实际 `.app`、`.dmg`、`.exe` 或安装包启动 |
| 窗口 | 默认尺寸、最小尺寸、居中、缩放、滚动和多窗口 |
| 品牌 | 应用名、Dock/任务栏图标、设置页图标和透明边缘 |
| 导航 | 外部链接、本地地址、返回、重载和退出 |
| 生命周期 | 首次启动、第二次启动、停止、崩溃恢复和卸载 |
| 分发 | 签名、公证、权限提示、自动更新和目标系统版本 |

## 本地一体化运行时

| 领域 | 建议检查 |
| --- | --- |
| 依赖 | Docker 或随包运行时是否存在，缺失时引导是否清楚 |
| 冷启动 | 无本地业务镜像时从发行包导入并启动 |
| 服务 | 前端、API、数据库、缓存、任务进程全部健康 |
| 隔离 | 端口、容器名、网络和数据卷不碰开发环境 |
| 数据 | 重启与升级后数据、密钥和卷可继续使用 |
| 网络 | 不依赖未声明的外网下载；远程地址遵守安全策略 |
| 体积 | 安装包和镜像大小与目标用户、磁盘需求相匹配 |

## AI 与 Agent 能力

| 领域 | 建议检查 |
| --- | --- |
| 无模型降级 | 模型未配置时基础产品能力仍符合承诺 |
| 路由 | 关键意图、模型选择和确定性回退通过当前门禁 |
| 确认 | 修改用户数据前提供提案并获得确认 |
| 追踪 | 关键执行能够定位输入、提案、调用、结果和错误 |
| 隐私 | 提示词、日志和评测数据不泄露个人信息或密钥 |
| 失败 | 超时、限流、模型不可用时提供可恢复反馈 |

## 证据等级

| 等级 | 定义 | 使用方式 |
| --- | --- | --- |
| A | 当前冻结基线上的真实产物或目标环境验证 | 可以支持发布结论 |
| B | 当前源码的构建、自动化测试或隔离运行验证 | 支持工程判断，仍需关键真实路径证据 |
| C | 近期历史报告、旧提交结果或开发环境观察 | 只能作为线索，不代表当前通过 |
| D | 文档计划、推断或未复现口头结论 | 视为未验证 |

关键 Go 结论至少需要对应的 A 或 B 级当前证据；安装、首次启动和升级等产物行为优先要求 A 级证据。
