# 桌面与学习空间五阶段实施记录（2026-09-06）

## 产品边界

PlanPilot 不是两套产品，而是一个产品、两个客户端和两类学习空间：官网只承担介绍、下载、帮助、隐私和定价；Web 默认访问共享学习空间；Desktop 访问同一共享空间，并提供本机增强能力；本机私密空间只在 Desktop 中由有明确需求的用户主动创建。

首次启动不要求用户选择“云端/本机”。默认登录共享学习空间；本机私密空间只在桌面设置、敏感资料导入或断网场景渐进出现。

## 阶段一：统一云端数据

已实现：Desktop 默认连接 Web 相同工作台，不再启动桌面专用 Docker 栈；新增 `workspaces`、`workspace_members`、`devices`；已有账号回填稳定的“我的学习空间”，新注册账号同步创建；目标、资料库、资料、Pilo 会话和掌握证据带 `workspace_id`，计划与任务通过目标继承边界；设备 API 按登录用户隔离。

仍需演进：多云端空间切换尚未开放，当前默认空间是唯一可选云端空间。

## 阶段二：桌面增强

已实现：安全会话、受限导航、协议唤起和连接恢复；工作台识别 Desktop bridge，并登记安装实例、版本、设备名与平台；本机目录只通过系统原生选择器授权。

未实现：文件夹监听、托盘、快捷记录、系统通知、离线操作队列和同步冲突预览。它们需要明确的 `operation_id`、`device_id`、`base_version`、幂等和人工冲突确认协议，不能用浏览器缓存冒充。

## 阶段三：本地模型

已实现：模型管理位于设置页；用户可指定存储目录；Desktop 递归扫描 `.gguf` / `.safetensors`，显示类型、大小和路径；支持 HTTPS 文件直链下载、进度显示和本机选择。

未实现：选择结果尚未接入 Pilo；断点续传、哈希/签名目录、模型许可核对、硬件适配和推理进程生命周期未交付。完整实现需要确定推理运行时（如 llama.cpp/MLX）、受信模型清单和下载源。

## 阶段四：本机私密空间

已实现准备层：用户可命名空间并指定本机目录；Desktop 用系统安全存储加密空间标识，建立 `files`、`index`、`backups` 隔离目录；界面明确“准备完成”不等于完整工作台，不提供虚假的进入按钮。

阻塞核心层：加密本地数据库和密钥恢复；全域本地 repository；本地向量索引与离线前端资产；加密导入、导出、恢复；本地模型与资料的完整推理链路。上述未实现，因此当前不能称为完整私密空间。

## 阶段五：版本、设备与安全治理

已实现：Desktop 版本提升并暴露给设置页；设备按安装实例登记、可撤销；旧 `3310` 配置自动迁移到统一 `3000` 工作台；主库迁移前保留恢复快照；旧桌面库只有核对后才删除；AI 学习对象修改继续遵循草案、预览、确认、写入、回读和撤销。

外部发布阻塞：Apple Developer ID 与 notarization、正式 HTTPS 域名、对象存储策略、更新服务和签名密钥尚未提供。

## 数据库设计

云端 PostgreSQL 是唯一云端事实源：

```text
User
└── Workspace（默认：我的学习空间）
    ├── Goal → Plan → Task
    ├── KnowledgeBase → KnowledgeItem → Chunk / Citation
    ├── CoachConversation
    ├── MasteryEvidence
    └── WorkspaceMember

User
└── Device（安装实例、版本、最后在线、撤销状态）
```

`workspace_id` 是学习空间边界，`user_id` 是所有权与审计边界，两者不能互相替代。本机目录、模型绝对路径和本地原文不写入云端数据库。
