# 手账纸稿全局风格实施报告

日期：2026-07-26

## 实施范围

- 删除设置页中原有五套“全局风格”配色入口；
- 新增独立界面风格“手账纸稿”，与默认、暗黑、护眼、手绘同级；
- 旧 `calm-*` 用户配置自动迁移为“手账纸稿”，色彩方案恢复为靛青；
- 不修改后端、数据库、业务数据或页面路由。

## 视觉实现

- 使用多层 CSS 渐变生成纸张纤维纹理，不依赖外部图片；
- 全局正文继续使用 Inter，标题和装饰文字使用 Patrick Hand；
- 文字和边框统一采用石墨色阶，赭石色仅用于重点操作；
- 应用框架与卡片使用轻微不规则圆角、铅笔边框和错位阴影；
- AI 每日简报改为横线便签，并在顶部增加半透明胶带；
- 今日任务卡片增加票据锯齿边；
- 图表网格使用虚线，曲线增加铅笔线条阴影；
- 弹窗和浮层统一为叠放纸片样式；
- 输入框、按钮和选择控件使用统一石墨边框。

## 设计边界

本轮使用 CSS 纹理和轮廓模拟手账感，没有引入位图纸张背景，也没有把正文替换成手写字体，以保证长文本、任务列表和编辑器的可读性。
