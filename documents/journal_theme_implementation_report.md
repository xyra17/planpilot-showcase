# 手账纸稿全局风格实施报告

日期：2026-07-26

## 实施范围

- 删除设置页中原有五套“全局风格”配色入口；
- 新增独立界面风格“手账纸稿”，与默认、暗黑、护眼同级；
- 旧 `calm-*` 用户配置自动迁移为“手账纸稿”，色彩方案恢复为靛青；
- 不修改后端、数据库、业务数据或页面路由。

## 视觉实现

- 使用多层 CSS 渐变生成纸张纤维纹理，不依赖外部图片；
- 全局正文继续使用 Inter，标题和装饰文字使用 Patrick Hand；
- 文字和边框统一采用石墨色阶，赭石色仅用于重点操作；
- 应用框架与卡片使用轻微不规则圆角、铅笔边框和错位阴影；
- AI 每日简报改为横线便签，并在顶部增加半透明胶带；
- 今日任务卡片增加票据锯齿边；
- 图表网格使用虚线，曲线增加铅笔线条阴影；
- 弹窗和浮层统一为叠放纸片样式；
- 输入框、按钮和选择控件使用统一石墨边框。
- 仪表盘主卡片和弹窗增加可缩放的不规则 SVG 边框；
- 信息卡增加纸张折角，AI 简报胶带及任务票据锯齿随当前手账配色变化；
- Lucide 图标在手账模式下增加轻微旋转和铅笔重影，正文图标语义保持不变；
- 核心弹窗与侧边抽屉补充 `dialog`、`aria-modal` 和可访问名称。

## 2026-07-26 色彩隔离与组件层补丁

青灰纸稿出现黄色控件的原因，是手账主题曾把 `.bg-gray-100` 固定为原木色
`#E9DECB`。本补丁删除了这项硬编码，并将以下视觉属性全部改为基于当前
`data-journal` 配色变量计算：

- 控件底色、悬停色；
- 卡片边框与错位阴影；
- 胶带、折角与票据锯齿；
- 图表网格与图标重影；
- 弹窗遮罩、表单纸面和主操作按钮。

因此原木、青灰、旧报纸三套方案不再互相泄漏强调色。

## 响应式、深色与可访问性

- 768px 以下取消外框装饰占位，弹窗改为底部纸片并限制为 `92dvh`；
- 针对三套手账配色分别提供系统深色变体，而非统一染成同一种深灰；
- 为键盘焦点提供 3px 高可见轮廓；
- 支持 `prefers-reduced-motion` 和 Windows `forced-colors`；
- 禁用控件保留可辨识状态并使用 `not-allowed` 光标；
- 表单占位文字、标签、正文分别使用当前配色的三级墨色。

## 设计边界

本轮使用 CSS 纹理和轮廓模拟手账感，没有引入位图纸张背景，也没有把正文替换成手写字体，以保证长文本、任务列表和编辑器的可读性。

## 专属配色

手账纸稿不直接使用普通色彩方案，而是提供三套保持纸张语义一致的专属配色：

- 原木纸稿：米白纸、石墨墨水、赭石重点色；
- 青灰纸稿：灰白纸、深青墨水、灰绿色重点色；
- 旧报纸稿：淡黄纸、炭黑墨水、暗红重点色。

配色选择按用户保存在本地，刷新页面后保持不变。
