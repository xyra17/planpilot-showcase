# Agent V2.1：任务工具与后台执行验收报告

日期：2026-07-27

## 完成内容

### 任务工具

- 创建一项或多项任务；
- 修改指定任务日期；
- 标记指定任务完成；
- 删除指定任务；
- 批量重新安排逾期任务；
- 全部写操作都经过 ChangeSet、审批、前值校验和用户归属校验；
- 创建、更新和删除均支持幂等或冲突保护；
- 已执行变更支持补偿撤销。

自然语言定位任务时优先使用引号中的完整标题。无法唯一定位任务时只返回提示，不生成猜测性写操作。

### 可编辑方案

工作台允许：

- 修改新任务标题和日期；
- 修改重新排期后的日期；
- 从批量方案中移除不希望执行的项目；
- 保存修改并重新生成审批哈希。

安全限制：

- 不能修改并发校验使用的原值；
- 不能改变任务 ID 或所属目标；
- 删除操作只能保留或移除；
- 不能加入原方案没有审查过的新操作；
- 日期和标题由服务端再次校验。

### 后台持久执行

- API 先保存 Run，再投递 Celery，不等待完整任务链结束；
- Worker 使用条件更新原子认领 Run；
- 重复消息不会产生并行执行者；
- 每两分钟扫描待执行和异常中断任务；
- `executing` 超过五分钟未更新会重新排队；
- Redis 临时不可用时，Run 仍保存在数据库中，由恢复任务补投；
- 支持排队、执行、暂停、继续、取消、失败重试、审批和撤销状态。

### 前端体验

- 增加创建、改期和重新规划示例指令；
- 显示 `queued`、`executing` 等真实后台状态；
- 执行中自动轮询，刷新页面可恢复；
- ChangeSet 提供内联编辑和移除；
- 执行完成或撤销后刷新全局任务 Context，首页与目标详情随即同步。

## 当前边界

- 当前自然语言 Planner 对任务标题采用保守匹配；复杂别名和模糊指代需要后续模型 Planner 提供候选，再由用户选择；
- 当前任务模型仍以日期为粒度，不能精确表达“周三晚上不可用”；
- 删除任务可恢复的前提是所属目标仍存在；
- 创建任务当前默认 30 分钟、中优先级，后续可把时长和优先级解析纳入结构化 Planner；
- 外部日历尚未启用，待内部工具评测稳定后再接 OAuth 和双向冲突处理。
