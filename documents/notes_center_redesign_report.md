# 笔记中心重构实施与验收报告

日期：2026-07-26

## 一、目标

将原先相互割裂的“知识笔记 / 学习记录 / AI 对话摘录”整理为统一笔记中心，同时保留不同记录场景的差异：

- 全部笔记：统一搜索和浏览所有用户笔记；
- 快速记录：低成本捕捉想法，并承接新保存的 AI 对话内容；
- 学习日志：按日期组织，支持关联目标和可选任务；
- 知识卡片：沉淀可复用、可复习的结构化内容。

## 二、实施内容

### 2.1 安全备份

- Git 标签：`backup/frontend-before-notes-center-20260726`
- 前端归档：`/Users/Admin/Desktop/PlanPilot_archives/frontend_before_notes_center_20260726.tar.gz`

归档仅包含 Git 跟踪的前端源码，不包含 `node_modules`、`.next` 或本地密钥。

### 2.2 统一入口与创建流程

- 笔记页新增“全部笔记、快速记录、学习日志、知识卡片”四个稳定 URL 标签；
- 顶部增加统一“新建笔记”菜单；
- 快速记录和知识卡片共用统一列表、搜索、编辑和删除交互；
- 新建采用草稿优先策略，编辑器上传图片时始终具备真实 `note_id`；
- 未保存的空草稿在取消时自动清理；
- 用户维护的笔记可在快速记录、学习日志和知识卡片间转换。

### 2.3 AI 摘录归位

- AI 对话中新保存的普通内容默认进入“快速记录”；
- 历史 `chat_note` 无需迁移数据库，可在“全部笔记”和“快速记录”中继续查看；
- 知识库不再承担笔记浏览职责，仅保留前往笔记中心的引导入口；
- 系统生成的 AI 摘录和任务笔记禁止转换类型，避免破坏来源语义。

### 2.4 后端兼容

- 笔记类型增加 `quick_note`；
- PATCH 接口支持修改用户维护笔记的类型和记录日期；
- 原有 `daily_log`、`flash_card`、`chat_note`、`task_note` 数据保持兼容；
- 本轮不需要数据库迁移。

## 六、验收后的范围收敛

根据 2026-07-26 的前端验收反馈，笔记中心进一步收敛为两个主要入口：

- 删除“全部笔记”和“快速记录”标签；
- 保留“知识卡片”和“学习日志”，默认进入知识卡片；
- 新的 AI 对话保存内容直接生成知识卡片；
- 历史快速记录和 AI 摘录仍在知识卡片列表兼容显示，避免已有数据失去入口；
- 后端继续识别 `quick_note`，仅用于历史数据兼容，不再提供新的创建入口。

## 七、最终命名与创建入口

根据第二轮界面验收，两个入口进一步调整为：

- “学习笔记”置于首位并作为无参数访问时的默认页签，对应原按日期组织的学习记录；
- “学习日志”置于第二位，对应原知识卡片列表，底层 `flash_card` 类型保持不变；
- 删除页面顶层含义重复的“新建笔记”下拉菜单；
- 学习笔记和学习日志分别在自己的工作区提供明确的新建按钮；
- 学习日志卡片删除重复的绿色类型标签，保留编辑、转换和删除操作。

本轮只调整信息架构与显示名称，不迁移数据库，也不修改已有笔记的类型和归属。

## 八、日期语义与目标详情联动

- 学习日志新增记录日期字段编辑、顶部日期筛选和卡片完整日期展示；
- 新建学习日志默认使用当天日期，编辑时可改为实际发生日期；
- 目标详情页“笔记”改名为“相关笔记”；
- 删除目标详情页重复的内嵌富文本编辑器，改为汇总关联该目标的学习笔记与学习日志；
- 从目标详情页新建内容时跳转到笔记中心，并自动预选当前目标；
- 目标详情页仅承担查看、分组和跳转职责，完整编辑继续由笔记中心负责。
- 学习日志定位为全局时间流，目标关联保持可选；未关联目标的日志仍在笔记中心正常展示，目标详情页只汇总明确关联到该目标的内容。
- 目标详情页的新建入口收敛为紧凑工具栏和单一“新建”菜单，避免两个大按钮抢占内容空间。

底层仍使用已有的 `note_date`、`daily_log` 和 `flash_card`，不需要数据库迁移。
